# Whisky Cabinet v1.0.6

ウイスキーのコレクション、複数人レビュー、フレーバー、価格帯、レア度、
開栓中10本、次に開けるボトルの抽選、購入予定5選を管理できる
単体HTML形式のブラウザアプリです。

## 特徴

- インストール不要
- 外部ライブラリ不要
- オフライン動作
- データはブラウザの **IndexedDB** に保存（写真を多く登録しても容量上限に達しにくい）
- JSONバックアップ・復元
- CSV出力
- スマートフォン・タブレット対応
- 対応端末ではカメラ撮影からボトル写真を登録可能
- ボトル写真を最大1200px・高画質で保存
- 一覧・詳細・抽選画面で写真全体を切り抜かず表示
- ボトル棚を地域・写真の有無・状態・種類・価格帯・キーワードで同時に絞り込み
- ホーム画面に地域別コレクションのドーナツグラフを表示
- タグはタップ選択方式（設定画面の「タグ管理」で追加・改名・削除・並べ替え）

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内の `index.html` と `README.md` をアップロードします。
3. リポジトリの `Settings` を開きます。
4. 左側の `Pages` を選びます。
5. `Build and deployment` の Source を `Deploy from a branch` にします。
6. Branchを `main`、フォルダを `/(root)` にして保存します。
7. 数分後に表示される公開URLへアクセスします。

## データ保存について

登録データは、利用端末・利用ブラウザごとの **IndexedDB** に保存されます。
（v1.0.2以前は localStorage に保存していましたが、写真を多く登録すると
容量上限に達する問題があったため、v1.0.3でIndexedDBへ移行しました。
以前のデータは、アプリを開くと自動でIndexedDBへ引き継がれます。）

GitHub Pagesへ公開しても、利用者同士でデータは共有されません。

ブラウザのデータ削除や端末変更に備えて、アプリ内の
「バックアップ保存」を定期的に使用してください。

なお、プライベートブラウジングや容量不足などでIndexedDBへ保存できない場合は、
画面上部に警告が表示されます。その際はバックアップを書き出してください。
